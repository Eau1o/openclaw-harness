# 工程控制论 (Engineering Cybernetics)

> **作者**: 钱学森 (Qian Xuesen)
> **中文名**: 《工程控制论》
> **英文名**: Engineering Cybernetics
> **初版时间**: 1954年（中文原版）
> **重要版本**: 1956年英文版（科学出版社）

## 背景

钱学森是世界著名物理学家，中国航天事业奠基人，被誉为"中国航天之父"。1954年，钱学森被美国限制自由期间，在家中完成此书。1955年钱学森回国后将此书献给新中国。

## 核心内容

本书是**控制论**（Cybernetics）在工程领域的系统化奠基之作。

### 主要理论贡献

| 概念 | 说明 |
|------|------|
| **工程控制论** | 将 Wiener 的 Cybernetics 理论系统地引入工程技术领域 |
| **反馈原理** | 系统通过反馈实现自调节和自稳定 |
| **最优化理论** | 系统在约束条件下寻求最优运行状态 |
| **系统可靠性** | 复杂系统的故障检测与容错设计 |
| **动态系统建模** | 用数学方法描述工程系统的行为 |

### 学科体系

```
控制理论 → 经典控制 → 现代控制 → 智能控制
                          ↓
                    工程控制论（钱学森，1954）
```

## 学术地位

1. **开创性工作**: 首次系统地将控制论与工程实践结合
2. **学科奠基**: 奠定了中国控制理论与系统工程学科发展的基础
3. **国际影响**: 英文版出版后受到国际学术界高度重视
4. **持续影响**: 书中的理论框架影响了后来的航空航天、导弹控制等领域

> **我的评注**: 《工程控制论》是钱学森在特定历史时期完成的理论巨著。它将控制论从生物学和数学领域引入工程技术，形成了系统性的工程控制理论。这与当前 Agent-First Engineering 中"建立反馈循环"的核心思想高度一致。本书对理解复杂系统的控制与优化仍有重要参考价值。
