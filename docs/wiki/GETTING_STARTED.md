# Wiki 知识库 — 快速入门

## 什么是 Wiki 知识库？

简单说：让你的 AI 助手成为你的"个人图书馆管理员"。

当你摄入一篇论文时，AI 会自动：
1. 读取并理解内容
2. 创建摘要页、提取关键概念、关联已有知识
3. 更新索引和日志
4. 标注矛盾和待核实点

**你只需要提问和审核**，所有繁琐的整理工作都由 AI 完成。

---

## 5 分钟上手

### 第一步：摄入你的第一篇资料

```
→ 把一个文件路径或 URL 发给我
→ 说"摄入 wiki"
```

例如：
```
摄入这个：https://example.com/your-article
```

AI 会自动创建相关页面，你可以在 Obsidian 中实时看到。

### 第二步：提问

```
→ 直接问问题
```

AI 会先从 wiki 中搜索答案，而不是每次都从零开始推理。

### 第三步：让知识累积

```
→ 问完有价值的分析，说"写回 wiki"
```

这样你的探索成果也会沉淀到知识库中。

---

## 目录结构

```
wiki/
├── sources/           # 原始资料（只读）
├── pages/            # AI 生成的页面
│   ├── entity/       # 实体：人/组织/产品
│   ├── concept/      # 概念：主题/理论/方法
│   ├── source/       # 来源摘要
│   └── synthesis/   # 综合分析
├── .schema.md        # 维护规范
└── log.md            # 操作日志
```

---

## 规则

1. **不要手动编辑 pages/ 目录**——交给 AI 维护
2. **sources/ 永远保持原始**——不可修改
3. **发现错误或矛盾**——告诉 AI 纠正

---

## 命令速查

| 你说 | AI 做的事 |
|------|-----------|
| "摄入 [URL/文件]" | 读取 → 分析 → 创建/更新 wiki 页面 |
| "查一下 xxx" | 搜索 wiki → 综合回答 |
| "写回 wiki" | 把当前回答创建为 synthesis 页面 |
| "wiki 体检" | 检查断链、矛盾、过期、孤儿页面 |
| "打开 Obsidian" | 在 Obsidian 中打开 wiki |
